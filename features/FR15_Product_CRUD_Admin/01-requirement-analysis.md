# FR-15 Product Management CRUD - Requirement Analysis

## Requirement Source

- SRS: FR-15
- Platform: Admin Web + API

## Expected Behavior

- Admin can create, view, update, and delete products.
- Product name is required and has maximum length 255 characters.
- Price is required and must be positive.
- Category is required and must be selected from existing categories.
- Updating one product must not change other products.
