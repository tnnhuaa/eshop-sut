# Domain Testing and BVA Agent Skill

This folder contains the reusable Agent Skill created during HW02 from the FR-06 Product Detail View workflow.

## Purpose

The skill helps generate human-reviewed test design artifacts for Domain Testing and Boundary Value Analysis. It is intended for reuse on later features such as FR-10, FR-15, and FR-05-M after the student supplies feature-specific context.

## Folder Contents

| Path | Purpose |
| --- | --- |
| `SKILL.md` | Main reusable workflow and guardrails |
| `templates/` | Output templates for future features |
| `examples/FR06-example/` | Worked example from FR-06 |
| `skill-change-log.md` | Change log for future skill improvements |
| `skill-evaluation.md` | Evidence of skill evaluation |
| `demo-video-links.md` | Placeholder for demo video links |

## Required Evidence For Each Skill Run

1. Input requirement.
2. Raw skill output.
3. Human review.
4. Corrected final output.
5. Skill improvement, if any.
