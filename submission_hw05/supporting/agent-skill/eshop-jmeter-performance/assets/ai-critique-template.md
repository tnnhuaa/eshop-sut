# AI Critique Draft Structure (200–300 words)

1. State which raw JTL/report evidence the AI analyzed.
2. Identify one useful interpretation and verify it with a concrete metric.
3. Identify one misinterpretation or unsupported optimization.
4. Explain the likely cause: prompt limitation, metric ambiguity, model limitation, or SUT behavior.
5. State the student's correction and whether the proposal is feasible under the observed hardware/environment.

The student must replace this structure with their own reviewed judgment. Do not mark it human-verified automatically.
